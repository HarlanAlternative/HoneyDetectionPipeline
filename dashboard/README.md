# Honey Production Analytics Dashboard

Interactive Streamlit dashboard backed by real USDA NASS honey production data (1998–2012).

## Run

```bash
streamlit run dashboard/app.py
```

Requires: `pip install streamlit plotly scipy scikit-learn pandas`

## Pages

| Page | Content |
|------|---------|
| **Executive Overview** | 8 KPI cards, production area chart, top-10 states bar chart, key findings summary |
| **Quality Distribution** | PQI histogram, tier pie chart, state-year heatmap, regional box plots |
| **Parameter Deep Dive** | Pearson correlation matrix, scatter plots with OLS trendlines, IQR vs IsolationForest outlier comparison |
| **Time Trends** | 4-panel annual time-series, regional yield trends, price band chart with regression annotation |

## Production Quality Index (PQI)

PQI is a composite score (0–100) built from two market-observable signals:

```
yield_z  = z-score of yieldpercol
price_z  = z-score of priceperlb
pqi_raw  = (yield_z + price_z) / 2
pqi_score = rescaled to [0, 100]
```

Higher yield-per-colony indicates colony health; higher price-per-lb indicates market quality premium. Both are directionally correct proxies for honey quality.

> **Why not use `IndustrialETLProcessor._calculate_quality_score()`?**
> That function requires laboratory physicochemical measurements — moisture (%), pH, diastase
> activity, and HMF (mg/kg) — which are not collected in the USDA production survey. PQI is
> the analytically appropriate substitute for public-dataset work.

## Data Source

- **Source**: USDA National Agricultural Statistics Service (NASS), Honey Production Survey
- **Original mirror**: Kaggle community mirror of USDA NASS data (public domain)
- **File**: `data/raw/honeyproduction_usda.csv`
- **Coverage**: 626 state-year observations · 44 states · 1998–2012 · 0 missing values
- **License**: Public domain (US federal government data)

```bash

pip install playwright
playwright install chromium
```
